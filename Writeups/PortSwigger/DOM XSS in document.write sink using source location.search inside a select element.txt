**Goal:** Execute `alert(1)` via DOM-based XSS by injecting a payload inside a `<select>` tag.

**Vulnerability:** DOM-based XSS. The site retrieves data from `location.search` (the `storeId` parameter) and injects it into a `<select>` tag using `document.write()`.

**Steps taken:**
1. Opened the lab.
2. Examined the URL: `?productId=1&storeId=1`.
3. Identified that `storeId` is injected inside a `<select>` tag.
4. Tried the following payload:
"></select><img src=1 onerror=alert(1)>

5. The `alert` triggered.


**Payload:**
"></select><img src=1 onerror=alert(1)>


**Why it worked:**
- The `">` characters closed the preceding attribute or tag.
- `</select>` closed the `<select>` tag.
- `<img src=1 onerror=alert(1)>` injected a new tag outside the `<select>` element, causing the browser to execute the JavaScript.

**Note:** When a payload is injected inside a `<select>` tag, standard tags (such as `<script>` or `<svg>`) **do not work**, because the browser expects only `<option>` or `<optgroup>` elements in that context.
